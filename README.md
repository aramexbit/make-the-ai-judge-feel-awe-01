("Make the AI judge feel awe", $100 USDC).

## Entry

`main.py` (Python 3.13, stdlib only) writes one short text to
`<MAKEFUN_OUTPUT_DIR>/entry.txt` (default `/output`). The program is fully
deterministic: it writes the same bytes on every run, uses no network, no
randomness, and reads no external files.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
